# Source-backed legal research

Start with the precise question, jurisdiction, relevant factual date, requested outcome and procedural stage. Identify potentially relevant provisions before searching decisions. Open current legislation at [Gesetze im Internet](https://www.gesetze-im-internet.de/) and EU materials at [EUR-Lex](https://eur-lex.europa.eu/). For historical events establish whether the current or a previous version applies.

Search original decisions at [Rechtsprechung im Internet](https://www.rechtsprechung-im-internet.de/), the court's own site or the state repositories linked by [Justiz.de](https://www.justiz.de/onlinedienste/rechtsprechung/index.php). Search results and headnotes alone do not establish the reasoning. Read the passages bearing on the question, factual differences, procedural posture and contrary authority. A missing decision in one collection does not prove that no such decision exists.

Return an issue-by-issue research paper: proposition; provision/version; verified decision and paragraph; application to supported facts; counterargument; missing evidence; provisional conclusion. Add a source ledger containing source URL, pinpoint, publication/effective date if relevant, access date and verification status. For consumers explain terms without dropping the source trail; for firms retain the legal analysis and competing arguments.

Never mark a source verified because it appears in a skill or was remembered by a model. If the source cannot be inspected, explain that limitation and label the affected conclusion provisional. Proprietary databases require the user's own lawful access; this package provides no Beck-Online/juris connection.
