# Case intake

Use the application to choose a generated internal number or preserve an existing one. Record audience, client/own party, opposing party, procedural roles, contact details, chronology, evidence, desired result, jurisdiction, area of law, stage, court/authority, separate court/opponent references, received dates, known deadlines, value and fee basis. Distinguish the account holder from the client in a law-firm case.

For each important fact record its source, date and whether it is confirmed or disputed. Build an evidence list with document/page, supported fact, missing proof and proposed follow-up. Do not treat a newly uploaded file as already read or OCR-extracted.

Return a concise matter summary, chronology, party/reference map, missing-information checklist and proposed next tasks. List any source-supported potential time-sensitive issue for human review. A manually marked conflict-check status is not an automatic conflict search. An automatically generated intake summary must not overwrite confirmed particulars without the user's authorised edit.
